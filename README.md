**今日の流れを、そっとひらく。**

月夜のおみくじは、夜の静けさのなかで、いまの自分に届く小さな言葉を受け取るための静的Webアプリケーションです。墨色、月光、銅色、青緑の細線で構成した「月夜の書院」を舞台に、ひと呼吸してからおみくじを引く体験をつくります。

[日本語](README.md) | [公開サイト](https://watanabe3tipapa.github.io/omikuji/)

## コンセプト

### なぜ「月夜のおみくじ」なのか

おみくじは、未来を一方的に決めるものではありません。迷いのなかにいるとき、軽やかに進みたいとき、自分の心を見つめ直すための小さなきっかけです。このサイトでは、画面を開いた瞬間に結果を出すのではなく、意識して「おみくじを引く」ことで、言葉を受け取るまでの一拍を大切にしています。

| 体験 | 月夜のおみくじの対応 |
| --- | --- |
| 心を整える | 導入文と余白のある画面で、抽選前にひと呼吸おく |
| 言葉を受け取る | 運勢ごとに短い読み解きと、三つの具体的なしるしを提示 |
| 自分の歩幅へ戻る | 未来を断定せず、今日の行動に添えられる表現を採用 |
| 引きすぎない | 三回目までは運勢を引ける。四回目には悪夢が現れ、五秒後に最初へ戻る。 |

> おみくじは未来を決めるものではなく、心を見つめるための小さなきっかけです。

## 特徴

- **月夜の書院を思わせるビジュアル**: 墨色の背景、格子、生成りの紙面、銅色の月光、青緑の罫線で静かな没入感をつくります。
- **六種類の運勢**: 大吉・中吉・小吉・吉・末吉・凶の六種類を、重み付けを設けずにランダムで抽選します。
- **言葉のある結果画面**: 各運勢に「読み解き」「願いごと」「ひととの縁」「開運のしるし」を用意しています。
- **三回までの抽選と悪夢**: 三回目までは直前と異なる運勢を表示し、四回目の試行では五秒間の悪夢演出の後に初期画面へ戻ります。
- **外部ランタイム不要**: PyScriptなどの外部実行環境を使わず、HTML / CSS / JavaScriptだけで動作します。
- **アクセシビリティ**: キーボードフォーカス、抽選結果のライブ通知、`prefers-reduced-motion` による動きの抑制に対応しています。
- **GitHub Pages対応**: `main` ブランチへの反映を契機に、GitHub Actionsから静的サイトとして公開します。

| --- | --- | --- |

### 1. リポジトリを取得する

```bash
git clone https://github.com/watanabe3tipapa/omikuji.git
cd omikuji
```

### 2. ローカルで開く

最も簡単な方法は、`index.html` をブラウザで直接開くことです。ローカルサーバーを使う場合は、次のコマンドを実行してください。

```bash
python3 -m http.server 8000
```

ブラウザで [http://localhost:8000](http://localhost:8000) を開くと、月夜のおみくじを試せます。

## おみくじの仕組み

抽選はブラウザ内で完結します。`main.js` が六種類の運勢からランダムに一つを選び、運勢名と読み解きを結果カードへ反映します。三回目までは直前の結果と同じものを選ばず、四回目の試行では悪夢のビジュアルを五秒間表示して初期状態へ戻ります。

| 項目 | 内容 |
| --- | --- |
| 抽選対象 | 大吉・中吉・小吉・吉・末吉・凶 |
| 抽選方法 | `Math.random()` を用いたクライアントサイド抽選 |
| 結果内容 | 読み解き、願いごと、ひととの縁、開運のしるし |
| 抽選上限 | 三回まで引ける。四回目を試すと、悪夢オーバーレイを五秒間表示して初期状態へ戻る。 |
| 状態管理 | ページを再読み込みすると初期状態へ戻る。個人情報・結果履歴は保存しない。 |

## デザインとアクセシビリティ

画面は大きな導入コピーと、紙のおみくじを模した操作カードで情報の優先順位を分けています。小さな画面では一列のレイアウトへ切り替え、カードと主要操作を読みやすい大きさで保ちます。

| 対象 | 対応 |
| --- | --- |
| キーボード操作 | ボタンとリンクに明確なフォーカス表示を提供 |
| 抽選結果 | `aria-live="polite"` で結果変更を読み上げ可能にする |
| 視覚的な動き | `prefers-reduced-motion` が有効な環境ではアニメーションを最小化 |
| モバイル表示 | 900px以下で一列、640px以下で間隔・文字・カードを最適化 |
| 色の役割 | 運勢や操作の識別を色だけに依存せず、文言と構造を併用 |

## 公開

`main` ブランチへ変更を反映すると、[GitHub Actions](.github/workflows/deploy.yml) がGitHub Pagesへデプロイします。リポジトリの **Settings → Pages** では、公開元を **GitHub Actions** に設定してください。

公開先: [https://watanabe3tipapa.github.io/omikuji/](https://watanabe3tipapa.github.io/omikuji/)

## 確認

JavaScriptの構文確認は、リポジトリ直下で次のコマンドを実行します。

```bash
node --check main.js
```

ブラウザ上では、三回分の抽選、四回目の悪夢表示、五秒後の初期化、キーボード操作、狭い画面幅での表示を確認してください。
