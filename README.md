# 月夜のおみくじ

> 今日の流れを、そっとひらく。

静かな夜の書院をイメージした、軽量な静的おみくじサイトです。ひと呼吸してからおみくじを引くことで、運勢と短い言葉を受け取れます。

## 特長

| 項目 | 内容 |
| --- | --- |
| 世界観 | 墨色、月の光、銅色、青緑の細い線で構成した和モダンなデザイン |
| おみくじ | 大吉・中吉・小吉・吉・末吉・凶の6種類と、それぞれに対応する言葉 |
| 操作 | 初回の「おみくじを引く」と、結果表示後の再抽選に対応 |
| アクセシビリティ | キーボード操作、フォーカス表示、結果のライブ通知、動きを抑えるOS設定に対応 |
| 構成 | ビルド工程・外部ライブラリ不要のHTML / CSS / JavaScript |

## ローカルで試す

`index.html` をブラウザで開くだけで動作します。ローカルサーバーを使用する場合は、リポジトリ直下で次を実行してください。

```bash
python3 -m http.server 8000
```

その後、`http://localhost:8000` にアクセスします。

## ファイル構成

```text
.
├── index.html   # 画面構造とSEOメタデータ
├── main.css     # レイアウト、配色、アニメーション、レスポンシブ対応
├── main.js      # おみくじの抽選・表示ロジック
└── .github/workflows/deploy.yml  # GitHub Pages デプロイ
```

## 公開

`main` ブランチへ変更を反映すると、GitHub Actions がGitHub Pagesへデプロイします。リポジトリの **Settings → Pages** で、公開元が **GitHub Actions** に設定されていることを確認してください。
