# 抽選・悪夢演出仕様

> **対象バージョン:** v0.3.0  
> **対象画面:** 月夜のおみくじの抽選カード

## 目的

月夜のおみくじでは、運勢を何度も引き直すのではなく、引いた言葉を一度受け取るための間を大切にします。そのため、同一ページ表示中の抽選回数を三回に制限します。四回目の試行はエラーとして扱わず、静かな世界観を保ったまま七秒間の「悪夢」の場面へ遷移します。その後、三秒間の空白を挟んでから最初の状態へ戻ります。

## 状態遷移

抽選状態はブラウザ内だけで管理し、ページを再読み込みした場合は必ず初期状態から開始します。結果や回数は外部サービス、Cookie、`localStorage` に保存しません。

| 状態 | 表示 | 可能な操作 | 次の状態 |
| --- | --- | --- | --- |
| 初期状態 | 「今宵のしるし」と初回抽選ボタン。残り回数は3回。 | おみくじを引く | 1回目の結果 |
| 1回目の結果 | 運勢と読み解き。残り回数は2回。 | もう一度ひらく | 2回目の結果 |
| 2回目の結果 | 運勢と読み解き。残り回数は1回。 | もう一度ひらく | 3回目の結果 |
| 3回目の結果 | 運勢と読み解き。残り回数は0回。 | もう一度ひらく | 悪夢演出 |
| 悪夢演出 | 全画面の非写実的な神社回廊のビジュアルと案内文。 | 操作なし | 7秒後に空白画面 |
| 空白画面 | 黒一色の全画面。画像・文字・操作要素を表示しない。 | 操作なし | 3秒後に初期状態 |

三回目までの抽選では、直前と同じ運勢を連続して表示しません。六種類の運勢が一種類しか存在しない状態に限り、その唯一の運勢を表示します。

## 悪夢演出

四回目の試行を検出すると、`nightmare-omikuji.jpg` を背景にした全画面オーバーレイを表示します。ビジュアルは、風に揺れる空白のおみくじ紙と古い神社の回廊を描く非写実的なものです。流血、身体損壊、人物の顔、突然の怪物などを用いず、静かな不穏さによって「引きすぎた」ことを伝えます。

| 時点 | 振る舞い |
| --- | --- |
| 0秒 | 悪夢オーバーレイを表示し、「夜は、ここまでです。」を案内する。背景画像をゆるやかにズームする。 |
| 0〜7秒 | 青緑の進行線を、満ちた状態から静かに減衰する形で表示する。 |
| 6.25秒 | 悪夢オーバーレイのフェードアウトを開始する。 |
| 7秒 | 画像・文字・進行線を隠し、黒一色の空白画面へ移行する。 |
| 7〜10秒 | 黒一色の空白画面を維持する。 |
| 10秒 | 空白画面を非表示にし、抽選回数・表示内容・スクロール位置を初期化する。 |

空白画面の三秒間が終わると、残り回数が3回へ戻り、抽選カードは「今宵のしるし」を表示します。キーボードフォーカスは初回抽選ボタンへ戻します。

## アクセシビリティ

抽選回数は `aria-live="polite"` の領域で伝えます。運勢の結果も同様にライブ通知されるため、画面を見ない利用者にも抽選結果の更新が届きます。悪夢演出の案内は `aria-live="assertive"` とし、四回目を試行した直後に重要な状態変更として通知します。

視覚的な動きを抑える設定がOSで有効な場合、既存の `prefers-reduced-motion` ルールにより画像のズーム、フェード、進行線のアニメーションを最小化します。七秒間の悪夢、三秒間の空白、十秒後の初期化という時間制御そのものは、動きの設定にかかわらず維持します。

## 確認手順

ブラウザで初期画面を開き、残り回数が3回と表示されることを確認します。三回続けて抽選し、残り回数が2回、1回、0回へ順に変化することを確認します。四回目には新しい運勢が表示されず、悪夢オーバーレイが七秒間表示されることを確認してください。続く三秒間は画像・文字・操作要素のない黒一色の空白画面となり、十秒後に初期画面と残り3回の表示へ戻ることを確認します。

実装の構文確認には、リポジトリ直下で次のコマンドを使います。

```bash
node --check main.js
```
